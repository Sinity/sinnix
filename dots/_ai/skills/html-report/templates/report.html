Element crib (delete before shipping)

Paths: openable, and previewable without any request

A plain openable path — /etc/hostname. Add a <template class="pop"> child and it previews on hover, focus, or click-to-pin (Esc closes; ctrl/cmd-click still opens the file):

/realm/project/polylogue/CLAUDE.md

The <template> must be a child of the element it previews, not a sibling — :has(> template.pop) binds the popup to the direct parent, so a stray sibling silently attaches the preview to the whole paragraph.

You must paste the excerpt in yourself — the page cannot read the disk. That is the point: the preview is a quote you took while you had the file open, so it stays true offline and forever. Editor-opening links work too: vscode://file/<abs-path>:<line>.

Code with chrome

Wrap each line in <span class="line"> for numbering; add hl to the lines that matter. Token classes are tk-k keyword, tk-s string, tk-c comment, tk-n number, tk-f function — apply them as you write, since a runtime highlighter would be a dependency for something you already know the answer to. .lang on the language chip gives it the accent color shown above.

Quotes vs. your own narration — never the same box

Narration is a plain paragraph, exactly like this one — no border, no background. The moment you're relaying words someone actually said or wrote, switch construct:

DOM should either get stable provider ids, or be retired for providers with a working native path.assistant, turn 41

blockquote.q renders in an italic serif face — the one deliberate typographic pairing in this template — plus an oversized opening quotation mark, so a reader can tell "this is reported speech" without parsing the sentence. Add .user or .ext to recolor the left bar for who's speaking; the serif treatment stays constant regardless of speaker, because quote-ness and who said it are different facts. A short quote inside a running sentence doesn't need the full block — use <span class="iq"> instead: it reads like this, a tinted italic run, no box.

Sidenotes — asides that pop, not a fake margin column

A claim that needs a caveat but not an interruption[†] gets a small superscript marker instead of competing for column width.

Epistemic basis

Tag a claim with what it actually rests on: measured ran a query, derived computed from measurements, inferred reasoned from evidence, assumed taken on faith and untested. The last one is not an admission of failure — an unlabelled assumption is.

In prose, delimit the tag's scope with a claim tint running through exactly the certified words: 13,671 rows are byte-identical duplicatesmeasured — or 79% of quarantined bytesderived, probably a capture-time defectinferred. Convention for measurement-heavy reports: state once in the meta basis row that measured is the default, and tag only the exceptions — a page where every number wears an identical green chip has hidden the ones that matter.

Computed tiles — the summary cannot contradict the body

A living document revised across sessions drifts: someone updates a row and forgets the headline (confirmed failure, 2026-08-02: one report simultaneously claimed 128, 24, and 101+27 for the same count in three places). Any summary number countable from this page's own rows should be <span class="n" data-calc="count:#t1 tbody tr:not(.closed)"> — filled from the live DOM at load. sum:SELECTOR adds data-v (else numeric text) over the matched elements. Hand-write only numbers that come from outside the document.
