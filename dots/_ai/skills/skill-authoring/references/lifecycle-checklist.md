# Skill Lifecycle Checklist

- [ ] Name uses lowercase letters, digits, and hyphens.
- [ ] Description states the capability and concrete situations that should trigger it.
- [ ] Non-trigger examples are known before forward testing.
- [ ] Main instructions are concise and under the documented line budget.
- [ ] References are directly linked and resolve relative to the skill directory.
- [ ] No global `CLAUDE.md` or repository contract is copied into the skill.
- [ ] Validator output is clean.
- [ ] At least one trigger and one non-trigger request were observed.
- [ ] Retirement has evidence of a shipped replacement and no remaining route owner.
