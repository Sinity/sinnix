argument-hint: "[three or more situations]"

Use repertory-grid-like triadic comparisons about ${@:-projects, possibilities, situations or people}. Offer three concrete examples if the user has not supplied them; label them invented examples, not user preferences. Ask which two share an important property that distinguishes them from the third and in what respect. Let the user name both poles before proposing categories. Change the triad when useful; retain a construct only when the user actually expressed it. No psychological diagnosis or trait scoring.
